# 기능 명세: BO2 Jetson 흠집 탐지

**기능 브랜치**: `claude/project-thread-sy1p9l-detect` (Spec Kit 기본값은 `feature/002-jetson-detection`)

**작성일**: 2026-11-02

**상태**: 초안 (계약 확인 1건 대기)

**입력**: 백로그 BO2 설명: "부스 Jetson Orin Nano에서 YOLO11-seg TensorRT FP16 엔진으로 흠집 4종을 고해상 타일 추론하고, 결과를 gateway를 거쳐 capture-server에 올린다(FR-INS-01 부스 쪽, NFR-01). 엔진은 Jetson에서 직접 빌드한다. 수용 기준: 부스 한 세트 추론이 30초 안에 끝나고(11/6 실측), 결과마다 modelVersion이 남는다."

**요구사항 ID**: FR-INS-01(부스), NFR-01

## 명확화

### 세션 2026-11-02

- Q: 어떤 사진을 탐지하나요? → A: 세트의 면 사진 전부(SLATE 제외). 1080p 원본을 겹치는 타일로 잘라 엔진 입력 크기로 추론한다
- Q: 타일 경계에서 같은 흠집이 두 번 잡히면? → A: 원본 좌표로 되돌린 뒤 같은 클래스끼리 상자 IoU 0.5 이상이면 신뢰도가 높은 것만 남긴다
- Q: 클래스 이름은? → A: 모델의 클래스 이름이 codes.yaml `inspection.defect_class`(scratch·dent·crack·stain)와 다르면 시작하지 않는다
- Q: modelVersion은? → A: 엔진 파일 옆 `model.json`의 `modelVersion`(예: `yolo11s-seg-v001-trt-fp16`). 없으면 시작하지 않는다
- Q: 결과 좌표·카메라 구분은? → **A 결정(11/2, contracts codes 0.6.0)**: Detection에 `camera`가 필수로 붙고 polygon은 그 사진의 원본 px다. 표준 좌표(펼친 면)로 바꾸는 일은 inspect-worker 정렬 뒤 capture-server가 한다. 부스는 펼치지 않는다

## 사용자 시나리오와 테스트 *(필수)*

### 사용자 스토리 1 - 찍은 세트를 부스에서 바로 탐지한다 (우선순위: P1)

운영 담당이 세트를 다 찍으면 Jetson이 면 사진마다 흠집을 찾아 결과를 모은다. 결과마다 모델 버전이 붙는다.

**독립 테스트**: 가짜 탐지기(정해진 상자·폴리곤을 내는 클래스)로 타일 자르기·좌표 되돌리기·중복 제거·결과 모으기를 확인한다.

**수용 시나리오**:

1. **주어진 상황** 1920×1080 사진, **동작** 타일로 자르면, **결과** 타일이 사진 전체를 빠짐없이 덮고 이웃 타일이 정해진 만큼 겹친다.
2. **주어진 상황** 타일 안의 폴리곤, **결과** 원본 좌표로 되돌린 폴리곤이 사진 안에 있다.
3. **주어진 상황** 겹치는 두 타일이 같은 흠집을 잡으면, **결과** 하나만 남고 신뢰도가 높은 쪽이다.
4. **주어진 상황** 세트를 탐지하면, **결과** 결과마다 면·조명·카메라·클래스·폴리곤·신뢰도와 modelVersion이 있고 SLATE는 탐지하지 않는다.
5. **주어진 상황** 모델 클래스가 codes.yaml과 다르거나 modelVersion이 없으면, **결과** 시작하지 않고 이유를 알린다.

### 사용자 스토리 2 - 한 세트 30초 안 (우선순위: P1)

**수용 시나리오**:

1. **주어진 상황** Jetson Orin Nano와 FP16 엔진, **결과** 부스 한 세트(필수 28장) 추론이 30초 안에 끝나고, 걸린 시간이 기록된다(11/6 실측).

### 사용자 스토리 3 - 결과를 capture-server에 올린다 (우선순위: P1, 계약 확인 뒤)

**수용 시나리오**:

1. **주어진 상황** 출고·반납 세트, **동작** 탐지가 끝나면, **결과** `POST /api/v1/captures/sets/{setId}/detections`로 올라간다(탐지마다 face·light·camera, 원본 px 폴리곤).

### 경계 상황

- 엔진 파일이 없거나 GPU를 못 쓰면 무엇이 없는지 알리고 촬영 도구는 계속 쓸 수 있다(탐지만 건너뜀).
- 흠집이 하나도 없으면 빈 결과도 modelVersion과 함께 남는다.

## 요구사항 *(필수)*

- **FR-001**: 면 사진을 겹치는 타일로 잘라 추론하고 원본 좌표로 되돌린다.
- **FR-002**: 타일 사이 중복을 클래스별로 지운다.
- **FR-003**: 결과마다 modelVersion을 남기고, 모델 클래스는 codes.yaml 4종과 같아야 한다.
- **FR-004**: 세트마다 추론 시간을 기록한다(NFR-01, 30초).
- **FR-005**: 결과를 capture-server에 올린다(계약 확인 뒤).

## 성공 기준 *(필수)*

- **SC-001**: 한 세트 추론 30초 이내(Jetson 실측).
- **SC-002**: 모든 결과에 modelVersion.

## 가정

- 가중치는 민서 집 PC에서 학습한 v001 ONNX(고정 1x3x640x640). 엔진은 Jetson에서 `trtexec --fp16`으로 빌드한다(`trace-booth build-engine`).
- 추론은 TensorRT 파이썬 + libcudart(ctypes) + numpy·OpenCV로 직접 한다. jetson2에 torch·ultralytics가 없어서다(11/3 확인).
