ID를 몰라도 돼요. 관리자 화면에서 출고를 시작한 기기는 빠른 검사 목록에 뜨고, 누르면 세 ID가 자동으로 채워져요.
수령·반납은 빠른 검사에서 찍어요. 관리자 화면에서 수령·반납을 시작하면 빠른 검사 목록에 그 기기가 '수령'·'반납'으로 떠요. 부스 코드를 넣어도 빠른 검사로 바로 넘어가요.
